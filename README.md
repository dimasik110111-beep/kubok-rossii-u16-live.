# Кубок России U16 — LIVE

Мобильная веб-страница и API для турнира ФХР «Кубок России» среди юношей 2011 г.р. (сезон 2026/2027). Интерфейс адаптирован для iPhone и Android.

- Сайт: https://kubok-u16-live.dimasik110111.workers.dev/
- Официальный турнир ФХР: https://junior.fhr.ru/tournaments/kubokrossii-25008909/
- Официальный календарь: https://junior.fhr.ru/tournaments/kubokrossii-25008909/calendar/

## API

| Endpoint | Что возвращает |
| --- | --- |
| `/health` | Проверка доступности Worker и список API |
| `/api/v1/matches` | Расписание и опубликованные результаты из всех групп/этапов |
| `/api/v1/live` | Проверка карточек матчей игрового окна и подтверждённые LIVE-матчи |
| `/api/v1/matches/{gameId}` | Детали конкретного матча: команды, счёт, периоды, статус и события |

Календарь агрегируется из 10 официальных AJAX-потоков ФХР (группы и плей-офф). Время турнира хранится по Москве. Календарь кэшируется до 60 секунд; проверка LIVE — до 10 секунд.

LIVE-статус не выводится только из наличия счёта: он подтверждается по статусу в карточке матча ФХР. `/api/v1/live` возвращает в `matches` только матчи со статусом `LIVE` или `LIVE_PAUSED`; `checkedMatches` содержит все проверенные карточки. Если ФХР не отдаёт статус или карточку не удалось проверить, API не должен выдавать такой матч за LIVE.

Периоды, таймер и события доступны только в том объёме, в котором ФХР публикует их в карточке матча. Пустые значения не подменяются догадками.

## Автоматическая публикация

Push в `main` запускает GitHub Actions и публикует Worker вместе со статической страницей через Cloudflare. Для публикации нужны GitHub Actions secrets:

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`
