# Локальное исправление надёжности

Изменения подготовлены локально. Публикация на Cloudflare не выполнялась.

- Каждый запрос к ФХР ограничен шестью секундами, включая чтение тела ответа.
- Ошибка отдельной группы сохраняет результаты остальных групп. Частичный календарь и неполный список команд кэшируются на пять секунд, чтобы повторная попытка могла быстро получить исправленные данные.
- Календарь без каталога групп явно помечается частичным.
- Сбой чтения или записи edge-кэша не скрывает доступные данные ФХР.
- Страница обслуживания с HTTP 200 не считается протоколом матча.

Проверка: `node --test test/worker.test.mjs` — восемь тестов прошли. Эта же команда добавлена перед шагом публикации в существующем CI.

Тесты покрывают зависание соединения и тела ответа, успешные группы при сбое соседней, недоступный кэш, частичный fallback-календарь, невалидную страницу протокола и корректный итоговый счёт. Реальный upstream может быть недоступен; в этом случае API возвращает частичные данные или явную ошибку, не выдумывая результаты.
