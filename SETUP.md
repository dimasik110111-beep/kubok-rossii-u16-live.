# Публикация Кубка России U16 LIVE

## Уже настроено в репозитории

- `src/worker.js` — API-шлюз к официальному календарю и карточкам матчей ФХР.
- `public/index.html` — адаптивная мобильная страница со списком матчей, группами, поиском и LIVE-индикатором.
- `wrangler.toml` — Cloudflare Worker и статические Assets.
- `.github/workflows/deploy.yml` — автоматическая публикация при push в `main` и smoke-тесты API.

## GitHub Secrets

В репозитории открой **Settings → Secrets and variables → Actions**. Должны быть добавлены:

1. `CLOUDFLARE_API_TOKEN` — Cloudflare API Token с правом **Account → Workers Scripts → Edit** для нужного аккаунта.
2. `CLOUDFLARE_ACCOUNT_ID` — Account ID Cloudflare.

Не отправляй API Token в чат и не вставляй его в исходный код.

## Как работает LIVE

1. `/api/v1/matches` собирает расписание из 10 AJAX-потоков ФХР и обновляет кэш примерно раз в минуту.
2. `/api/v1/live` выбирает матчи текущей даты и предыдущего дня в окне от 3 часов до начала до 8 часов после начала.
3. Worker запрашивает карточки выбранных матчей и читает фактический статус ФХР, счёт, периоды и опубликованные события.
4. В ответе:
   - `matches` — только матчи со статусом `LIVE` или `LIVE_PAUSED`, подтверждённым страницей ФХР;
   - `checkedMatches` — все проверенные карточки, включая запланированные и завершённые;
   - `liveVerified` — true, если в окне была хотя бы одна карточка и все карточки удалось проверить. Это не означает, что сейчас обязательно идёт матч.
5. Мобильная страница обновляет LIVE примерно каждые 15 секунд, календарь — раз в минуту.

Периоды, игровой таймер и события показываются только если ФХР реально отдаёт их в карточке. Если ФХР не публикует таймер или события, приложение не подставляет выдуманные значения.

## Проверка после публикации

GitHub → **Actions** → последний запуск **Deploy Cloudflare Worker**. Успешный запуск должен закончиться зелёным статусом. Затем открой сайт по адресу выше.
